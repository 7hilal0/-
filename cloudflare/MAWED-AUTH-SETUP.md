# إعداد خدمة التحقق لموعد

لخطوات إعداد المشروع الموحد (الموقع + بوت Maw'ed + Cloudflare)، راجع:
[`MAWED-PROJECT-SETUP.md`](./MAWED-PROJECT-SETUP.md).

هذا الملف يشرح نقاط API الحالية:
- `POST /auth/request` مع `{"username":"DiscordUsername"}`
- `POST /auth/verify` مع `{"username":"DiscordUsername","code":"1234"}`

**الحالة:** ملفات Worker والمخطط موجودة في المستودع، لكن Worker لم يُنشر بعد، وقاعدة D1 الجديدة لم تُنشأ. واجهة الموقع لا تستخدم API منشورًا حتى الآن. لا تعتبر تسجيل الدخول جاهزًا قبل نشر الخدمة وتحديث عنوان API واختبارها.

نجاح التحقق يؤكد امتلاك المستخدم لحساب Discord لهذه العملية فقط؛ لا ينشئ جلسة دائمة للموقع. يلزم إضافة جلسة آمنة موقعة قبل اعتماد تسجيل الدخول الحقيقي.

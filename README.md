# موعد | Maw'ed — منصة الفعاليات

واجهة تجريبية مستقلة لتنظيم الفعاليات والمسابقات والتحديات الإبداعية، مع دعم العربية والإنجليزية.

## الموجود في النسخة الحالية
- صفحة رئيسية متجاوبة مع البحث والتصنيفات.
- فعاليات تجريبية توضح شكل الموقع.
- نموذج إنشاء فعالية يضم النوع والوصف والمواعيد والحد الاختياري للمشاركين والمرفقات.
- تجربة تصويت تحفظ العلامة في المتصفح.
- إعداد GitHub Actions للنشر على GitHub Pages.

## مهم قبل الإطلاق الحقيقي
هذه نسخة واجهة أمامية تجريبية. تسجيل Discord، وموافقة الإدارة، ورفع الملفات، والتصويت الموثوق، وحسابات الأعضاء والجوائز المشتركة **ليست متصلة بخادم أو قاعدة بيانات بعد**. البيانات التجريبية محلية وليست مشتركة بين الزوار.

## النشر
افتح Settings → Pages في المستودع، واختر GitHub Actions إن طُلب منك ذلك. بعد ذلك افتح Actions وتابع سير عمل Deploy Maw'ed to GitHub Pages.

## الخطوة التالية للإطلاق
يلزم Backend آمن (مثل Cloudflare Workers) وقاعدة بيانات وتخزين ملفات. يجب أن يبقى Discord client secret في الخادم ولا يوضع في ملفات الواجهة العامة.


## بوت Maw'ed والربط
ملفات إعداد البوت وخدمة التحقق موجودة ضمن نفس المستودع في مجلد `cloudflare/`.
ابدأ من [دليل إعداد مشروع موعد الكامل](./cloudflare/MAWED-PROJECT-SETUP.md).

**تنبيه:** توحيد الملفات في مستودع واحد لا ينشر Worker تلقائيًا. خدمة Cloudflare وقاعدة D1 ما زالتا بحاجة إلى إعداد ونشر واختبار.
